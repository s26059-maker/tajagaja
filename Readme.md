# 타자가자 ⌨️

재밌게 타자 연습하면서 속도를 올리는 웹 서비스

## 소개
기존 타자 연습은 재미가 없어서, 좋아하는 노래나 직접 고른 글로 연습할 수 있게 만들었습니다.

## 주요 기능
- **노래 따라치기**: 유행하는 노래 가사를 붙여넣고 따라 치기
- **내 글로 연습하기**: 치고 싶은 글을 복붙하면 바로 연습 화면 생성
- **실시간 표시**: 치는 동안 맞은 글자와 틀린 글자를 색으로 구분하고, 정확도와 타수를 바로 보여줌
- **결과 확인**: 다 치면 정확도, 타수, 오타 수 표시

## 기술 스택
| 구분 | 사용 기술 |
|---|---|
| 서버 | Java 17, Spring Boot |
| 화면 | HTML, CSS, JavaScript |
| 빌드 | Gradle |

## 실행 방법
```bash
./gradlew bootRun
```
실행 후 브라우저에서 `http://localhost:8080` 접속

## API
| 메서드 | 주소 | 설명 |
|---|---|---|
| GET | `/api/texts` | 글 목록 조회 |
| GET | `/api/texts/{id}` | 글 하나 조회 |
| POST | `/api/texts` | 내 글 추가 |
| POST | `/api/results` | 결과 계산 (정확도·타수·오타) |
